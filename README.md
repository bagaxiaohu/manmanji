# 慢慢记

给她的考研英语微信小程序。原生 WXML / WXSS / JavaScript，无需安装 npm 依赖，无需后端。

## 在电脑上打开

1. 安装并打开微信开发者工具，选择「小程序」→「导入项目」。
2. 项目目录选择 `E:\CodexProject\背单词小程序`。项目配置会自动定位 `miniprogram/`。
3. 本地查看可使用工具提供的测试号或游客模式；当前配置里的 `touristappid` 仅用于本地开发。若工具要求 AppID，请使用自己的小程序 AppID。
4. 编译后可以查看首页、开始学习、搜索词库和修改设置。没有服务端请求，不需要配置服务器域名。

## 让她在手机上使用

本地模拟器运行不代表已经发布。需要先注册自己的微信小程序账号，把 `project.config.json` 的 `appid` 换成该账号的真实 AppID，并把开发者微信加入项目成员。手机预览、体验版及正式发布均以账号权限和微信开发者工具当前要求为准，游客 AppID 不能作为可分享的上线账号。

配置真实账号后，可在开发者工具中预览真机。长期给她试用时，上传开发版本、在小程序后台设为体验版并添加她为体验成员；账号如果没有对应权限，按后台提示处理。正式发布之前核实个人主体开放类目、备案及审核要求。当前尚未登录账号、真机预览或发布。

## 已实现

- 主词表按 Word List 1–30 逐组学习，每轮包含第一个未完成 List 的剩余新词，完成后可当天继续下一组。原有进度自动接续，不受每日目标限制。
- 其他词库的新词目标默认每天 20 条，可调为 5–100 条。目标是提醒而不是上限，达标后仍可继续下一批。
- 四类词库：主词表 Word List 1–30、偶考词、简单词、补充词，也可选择全部。
- 到期复习优先，然后安排当前 List 或非 Word List 新词。非 Word List 目标按当天所有非主词表新词合计，主词表学习不消耗该目标；达标前补足目标，达标后每批按目标数继续，直至所选词库的新词学完。选择全部词条时先依次学习 Word List，再学习其他词条。
- 先按「认识 / 有点模糊 / 忘记了」回想，再显示释义。选择认识或有点模糊后，可点「下一词」确认，或点「记错了」直接保存为忘记了并进入下一词；选择忘记了后只显示「下一词」。保存失败时保留当前释义及纠正结果，可重试「下一词」。
- 忘记了（含记错了）：本轮末尾再出现一次，若仍忘记则约 10 分钟后到期。有点模糊：次日到期。认识：按 1、3、7、14、30、60 天逐步延长间隔。
- 收藏复习、英文及中文搜索、词条详情、分页词库、近七天足迹。
- 称呼固定为「小小欣宝贝」，不可在设置中修改；可自定义鼓励语；本地自动保存；通过剪贴板导出及恢复 JSON 备份。
- 保存失败时保留当前卡片，不把未保存的作答当作完成；读取异常时暂停写入，避免覆盖旧记录。

这里使用的是便于理解的固定间隔复习规则，不是经个人记忆数据拟合的算法。「已学」表示作答过，较长复习间隔也不等同于永久掌握。

## 刷刷刷模式

首页计划卡右上角可选择 Word List 1–30、之前完成的计划、或旧版本按日期保存的学习记录。手动选择会使用该组全部词条（含已学词），适合重学；选择「自动接续未学计划」恢复原来的顺序。历史计划保留当次词条及顺序，不会随新词进度变化。旧版本没有保存批次边界，因此旧日期记录按当日学过的词汇总展示。

首页「刷刷刷」和「听写」为并排的独立入口，使用所选计划。刷卡与独立听写分别保存中途进度。切换计划遇到未完成的记录时，会询问继续上次或开始所选。

普通学习和刷刷刷完成一组后都会询问是否听写；确认后使用刚完成计划的快照，避免自动进入下一组后听写范围变化。可以拒绝听写，继续学习或回首页。

首页的「刷刷刷」打开当前学习计划：到期复习加当前 Word List 剩余新词，或非主词表当前批次的新词。计划在进入时固定，进度自动保存，可退出继续。

- 左滑下一张、右滑上一张；回看已记录的卡片不会重复累计学习次数。
- 上滑忘记了，在后面额外出现两次；下滑有点模糊，额外出现一次。重复卡片会穿插，单词只剩一个时用间隔提示卡分隔。
- 每次显示单词卡片自动播放一次，点击音标重播。卡片至少 780rpx 高，长释义自然撑开。整张卡片（含音标与释义）都可滑动，点击音标从头重播；也提供按钮代替滑动。
- 刷完先显示本计划的完整单词总览，可进入听写，也可不听写直接完成本组并继续下一组。
- 听写混合「听英文，写单词和中文释义」「听中文释义，写英文并补全中文释义」。每题最多三遍，含自动播放；可空答提前下一题。上限随进度保存，返回页面不会重置。
- 只有整组交卷后才判断拼写、展示参考答案。中文含义可能有同义表达，需在结果页自评。可不完成全部自评就确认完成。拼写错误和明确自评错误的词安排复习；拼写正确但释义未自评的词保持原刷卡进度，不自动算答对或答错。

### 在线音源与真机配置

发音按 [UAPI 单词发音接口](https://uapis.cn/en/docs/api-reference/get-dictionary-audio) 的公开接口获取（`accent=uk` 优先），并尝试有道在线词典的英式发音；英式获取失败才尝试美式，卡片标注实际来源及口音。中文释义先尝试百度翻译在线朗读接口；该接口可能限制小程序来源，失败时尝试有道中文词条录音，摘读原释义中的短词义并标明「中文释义摘读」。短词义录音也可能缺失，失败时显示具体错误，不扣播放次数。已对 `advance` 英式及中文释义样本实测返回 MP3；未人工试听完整词库，不能保证每个词都有标准英音，公共接口的覆盖、可用性和配额可能变化。

小程序后台 → 开发管理 → 开发设置 → 服务器域名，在 **downloadFile 合法域名** 中按账号权限配置：

```text
https://uapis.cn
https://dict.youdao.com
https://fanyi.baidu.com
```

音频下载到微信临时文件后播放，不需要付费云服务，也不随代码包分发。卡片进入前预载本次计划英文音频；如果英、美式都取不到，会列出缺失词并提供重试，不会假装播放成功。中文朗读在听写该题时获取，失败时不计播放次数，可重试或跳题。音频链接为公开可访问服务，不代表授予整套录音再分发授权。

网络请求会将需要朗读的单词或词库释义发送给相应音频服务，不发送用户填写的听写答案、昵称或学习记录。上述域名必须由你在小程序后台配置；本次没有修改账号设置、绕过域名校验或发布小程序。开发者工具模板编译与模拟测试不代替 iPhone 真机音频测试。

## 本地数据

### 可选中文男声完整朗读

已准备腾讯云「智云」男声的云函数和客户端接入，但默认关闭，未部署、未开通计费服务。启用步骤见 `cloudfunctions/meaningSpeech/SETUP.md`。完整释义仅去除词性标签，不截取前 180 字；长释义分段连续播放。启用男声后不再降级为公共摘读录音。

所有学习数据保存在当前微信本地存储，不上传服务器、不跨设备同步。卸载、清理数据或换机前，请在设置里导出备份并粘贴到自己保存的文件中；恢复备份会替换当前数据，并需再次确认。本版未加入例句、通知或登录功能；普通学习与刷刷刷模式均提供单词自动发音及音标重播；听写在刷刷刷模式中提供。
